# College-Town Housing Market Dashboard

A responsive web dashboard exploring home sales in U.S. college towns using the College-Town Home Sales dataset.

## Project Overview

This website compares residential property sales across 18 cities and towns near university campuses. It presents summary statistics, median home sale prices by city, and sales counts in a chart and table.

## Key Features

- Summary statistics for 35,442 home sales
- Median sale price comparison across 18 cities and towns
- City-level sales counts and median price table
- Exclusion of sales under $10,000 from median price calculations
- Responsive layout for desktop and mobile devices

## Data Source

College-Town Home Sales Dataset, Version 1.0 (2026), University of Illinois–Deloitte Foundation Center for Business Emerging Technologies.

## Technologies

HTML, CSS, JavaScript, GitHub Pages, and ChatGPT Codex.
